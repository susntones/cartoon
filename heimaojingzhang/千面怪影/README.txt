# 《黑猫警长·新传：千面怪影》

> 续写经典动画《黑猫警长》的五集新故事。
> 森林里来了一个会“变色”的新反派，黑猫警长带领警士们，一边破案、一边读懂大自然，最终将其捉拿归案。
> 每一集的结尾都有一个 **「自然小课堂」**，里面的动物知识都是真实的科学事实，而且都是本集破案用到的关键线索。

## 故事背景

一只耳被抓以后，森林里安静了很久。有一天夜里，一艘走私船悄悄停在了森林河口，跳下船的是一只从远方热带雨林来的变色龙。它自称 **“千面”**，号称“谁也看不见我”。它来森林是为了偷光珍宝，还要把关在森林监狱里的老朋友一只耳救出来，一起称霸森林。

## 主要角色

| 角色 | 身份 | 特点 |
|---|---|---|
| **黑猫警长** | 森林公安局警长 | 眼睛瞪得像铜铃，射出闪电般的精明；开摩托车、会用手枪，最擅长观察和推理 |
| **警士虎斑、警士花斑** | 黑猫警长的助手 | 虎斑力气大、性子急；花斑细心，随身带着放大镜和笔记本 |
| **猫头鹰博士** | 森林图书馆馆长 | 见多识广，夜里的眼睛和耳朵特别灵，是警长的“自然顾问” |
| **蜂后金蕊和工蜂们** | 蜜蜂王国 | 用“舞蹈”说话 |
| **河狸阿坝一家** | 河边的“建筑师” | 牙齿是橘红色的，修大坝是一把好手 |
| **千面**（新反派） | 外来的变色龙大盗 | 能变颜色，两只眼睛能各看一边，舌头像弹簧一样能弹出去老远；狡猾、自负，最看不起“土里土气”的本地动物 |
| **一只耳** | 老反派，关在森林监狱 | 在千面的计划里扮演内应 |

## 全剧主线

1. **第一集**：千面第一次作案，只留下了奇怪的“钳子形”脚印。
2. **第二集**：警长确认罪犯是一只变色龙，也发现它在收集“开锁工具”。
3. **第三集**：千面拆掉大坝，想用洪水冲垮监狱的围墙，救出一只耳。警长保住了监狱，但千面逃走了。
4. **第四集**：千面设陷阱困住警长。萤火虫和猫头鹰博士帮忙救出了警长，还弄清了千面的弱点。
5. **第五集**：警长用紫外线灯和一个“寒冷的清晨”布下天罗地网，千面和一只耳一起落网。
