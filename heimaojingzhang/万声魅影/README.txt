# 《黑猫警长·新传：万声魅影》

> 《黑猫警长·新传：千面怪影》的续篇，共五集，每集20分钟。
> 千面落网后的第二年夏天，走私船的真正船长、会模仿一切声音的琴鸟 **“万声”** 来到森林。千面靠“看不见”，万声靠“听不出”。黑猫警长带领警士们，一边破案，一边弄懂 **声音** 的秘密，最终把万声捉拿归案。
> 每一集的结尾都有一个 **「自然小课堂」**，里面的动物知识和物理知识都是真实的科学事实，而且都是本集破案用到的关键线索；每一集还有一条 **成长道理**（不传谣、防诈骗、保护环境、知错能改、保护野生动物）。

## 故事背景

千面被抓以后，被送到了野生动物救护中心，等着回到热带雨林的家乡。可是，当初用走私船把千面带到森林来的那个“船长”，一直没有落网。

当时走私船上的水手都被抓住了，船长却趁乱驾着小船逃走了。第二年夏天，他换了一艘新船“夜莺号”，又悄悄开回了森林河口。船长是一只从澳大利亚来的 **琴鸟**，自称 **“万声”**。他能学会听过的几乎所有声音：鸟叫、电锯、警笛、摩托车喇叭，甚至黑猫警长说话的声音。他偷走了猫头鹰博士保管的《森林珍稀动物分布图》，要把森林里的穿山甲、娃娃鱼、画眉一只一只装上船卖掉。

## 主要角色

| 角色 | 身份 | 特点 |
|---|---|---|
| **黑猫警长** | 森林公安局警长 | 眼睛瞪得像铜铃，射出闪电般的精明；本季最擅长“用耳朵之外的办法”核实声音 |
| **警士虎斑** | 警长的助手 | 力气大、性子急，容易被假声音骗到，在一次次教训中学会了沉住气 |
| **警士花斑** | 警长的助手 | 细心，随身带着放大镜和笔记本，会用回声测距离 |
| **猫头鹰博士** | 森林图书馆馆长 | 警长的“自然顾问”，《森林珍稀动物分布图》的保管人 |
| **万声**（新反派） | 走私船“夜莺号”船长，琴鸟 | 能模仿听过的几乎任何声音；飞不高，只能从高处往下滑；爱显摆，每天清早都要在自己的土堆舞台上唱歌；把手下当工具 |
| **灰尾** | 万声的手下，狐狸 | 负责抓动物、搬笼子；最后被万声抛弃，说出了实话 |
| **千面** | 上一季的反派，变色龙 | 在救护中心等待回家；被万声抛弃过，这一季选择帮助警长，知错能改 |
| **松鼠跳跳** | 森林小学学生 | 第一集里传了谣言，后来带着同学们守路口、辟谣言 |
| **甲妈妈和小甲** | 穿山甲母子 | 视力差、鼻子灵；小甲总趴在妈妈的尾巴上 |
| **老鲵爷爷** | 青石涧深潭里的大鲵（娃娃鱼） | 活了六十多年，靠感觉水里的振动“听”世界 |
| **小蝠** | 回音谷里的蝙蝠 | 用超声波“看”路，万声听不见她的声音 |
| **萤火虫小亮、河狸阿坝一家、啄木鸟医生、蜂后金蕊** | 上一季的老朋友 | 在决战中帮助警长 |

## 分集目录

| 集数 | 标题 | 案件 | 科学知识 | 成长道理 |
|---|---|---|---|---|
| 第一集 | 半夜的电锯声 | 半夜的电锯声引起全森林恐慌，分布图被盗 | 声音是振动；声速与光速；猫的耳朵；琴鸟 | 听到消息先核实，不传谣 |
| 第二集 | 真假警长 | 万声冒充警长发假命令，深夜骗穿山甲出洞 | 穿山甲的鳞片、食性、嗅觉与保护 | 防诈骗三步走；几种办法一起核实 |
| 第三集 | 山涧里的哭声 | 万声学娃娃鱼叫，把小大鲵骗上浅滩 | 大鲵；空气中的声音难以进入水中；水中声速 | 保护溪流水源；不捕不吃野生动物 |
| 第四集 | 回音谷的陷阱 | 虎斑、花斑被假求救骗进山洞迷宫 | 回声与测距；蝙蝠回声定位与超声波；固体传声 | 遇险不乱跑；着急时最易被骗；知错能改 |
| 第五集（大结局） | 最后的歌声 | 月圆之夜河口决战，清晨土堆舞台擒获万声 | 琴鸟的求偶表演；光信号无法被声音假冒；光速与声速；鸣禽保护 | 学会声音更要听懂声音；野生动物“不买、不吃、不养、不随意放生” |

## 全剧主线

1. **第一集**：万声用模仿的电锯声、警笛声制造恐慌，趁乱偷走《森林珍稀动物分布图》，并在电话里用警长的声音向警长挑战。
2. **第二集**：万声发出一连串“假警长命令”。警长定下“三条规矩”和暗号，暗号却被万声偷听。甲妈妈靠鼻子识破了假警长，保住了自己和小甲。
3. **第三集**：万声学娃娃鱼叫，诱捕小大鲵。警长发现空气里的声音几乎传不进水里，就用水底敲击暗号通知所有大鲵，救回了三条小娃娃鱼。
4. **第四集**：虎斑、花斑被困回音谷。千面说出了万声的三个弱点；蝙蝠用超声波带路，警长贴着石壁听到了真正的求救暗号，救出两位警士。
5. **第五集**：月圆之夜，警察们“只看光、不听声”，识破万声的全部假声音，解救了船上的动物；第二天清晨，万声在自己的土堆舞台上，被一段学不会的新口哨吸引，最终落网。

| 段落 | 时间 | 时长 |

## 与上一季的衔接

- 上一季的主题是 **“看”**（颜色、伪装、光），这一季的主题是 **“听”**（声音、回声、振动）。
- 千面在第四集回归，从反派转变为帮手；一只耳在大结局客串。
- 上一季的萤火虫同步闪光、河狸修坝、啄木鸟的长舌头、猫头鹰的夜视，在本季决战中再次出场。
